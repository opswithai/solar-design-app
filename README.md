# Solar Design App

Design solar PV systems from satellite imagery: draw a roof or ground area, mark obstructions, auto-fill panels, size strings and inverters, simulate yearly energy, and export a proposal. Phase 2 adds financial analysis and PPA offers for developers.

See [CLAUDE.md](CLAUDE.md) for the workflow, stack and build order.

Status: planning done; Milestone 1 (map, roof drawing, keepouts, auto panel layout) is next.
